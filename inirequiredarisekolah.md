# Daftar Tugas Project Akhir: Website Manajemen Logistik

Berdasarkan *Template PROJECT AKHIR PENGEMBANGAN PERANGKAT LUNAK.pdf*, dokumen FASE 1 (Pendahuluan) terlihat sudah terisi dengan narasi latar belakang hingga analisis solusi. Oleh karena itu, tugas utama kelompok kalian adalah melanjutkan pengisian dan pembuatan aset/dokumen mulai dari **FASE 2 hingga akhir**.

Berikut adalah rincian tugas yang harus dikerjakan dan dilengkapi ke dalam laporan:

## FASE 2: PERENCANAAN DAN STRATEGI
Fase ini fokus pada perancangan sistem secara konseptual dan logika sebelum mulai membuat desain visual atau mengoding.
- [ ] **2.1 Analisis Kebutuhan Fungsional**: Mendeskripsikan fitur-fitur apa saja yang harus ada di dalam website (misal: fitur login, tambah barang, catat transaksi masuk/keluar, cetak laporan).
- [ ] **2.2 Analisis Kebutuhan Non-Fungsional**: Menentukan kebutuhan sistem di luar fitur (misal: keamanan, kecepatan akses, spesifikasi hardware/server, kompatibilitas browser).
- [ ] **2.3 Business Process**: Membuat alur proses bisnis dari sistem manajemen logistik yang akan dibuat, biasanya digambarkan dengan flowchart.
- [ ] **2.4 Use Case Diagram**: Membuat diagram Use Case yang menunjukkan interaksi antara aktor (misal: Admin, Staf Gudang) dengan sistem (website).
- [ ] **2.5 Activity Diagram**: Menggambarkan alur aktivitas dari masing-masing use case secara lebih detail.
- [ ] **2.6 Class Diagram**: Membuat struktur blueprint dari class-class yang akan dibangun pada sistem, beserta atribut dan method-nya (walaupun di template tertulis Smart Eco Bank, pastikan disesuaikan menjadi website Manajemen Logistik).
- [ ] **2.7 Entity Relationship Diagram (ERD)**: Merancang relasi antar entitas database (misal: tabel barang, tabel user, tabel transaksi).
- [ ] **2.8 Logical Record Structure (LRS)**: Menerjemahkan ERD ke dalam struktur tabel fisik yang siap diimplementasikan ke database.

## FASE 3: MERANCANG DAN WIREFRAMING
Fase ini berfokus pada desain antarmuka pengguna (UI) dan pengalaman pengguna (UX).
- [ ] **3.1 Wireframe**: Membuat sketsa kasar atau kerangka layout dari halaman-halaman utama website.
  - [ ] Versi Mobile
  - [ ] Versi Desktop
- [ ] **3.2 Prototype**: Membuat desain UI yang sudah interaktif dan berwarna (biasanya menggunakan tools seperti Figma).
  - [ ] Versi Mobile
  - [ ] Versi Desktop

## FASE 4: CONTENT CREATION (PEMBUATAN KONTEN)
Fase ini mendefinisikan aset visual yang digunakan di dalam proyek.
- [ ] **4.1 Typography**: Menentukan jenis font (huruf), ukuran, dan ketebalan yang digunakan untuk heading, sub-heading, dan body text pada website.
- [ ] **4.2 Color Style**: Menentukan palet warna (primary, secondary, background, text) yang digunakan beserta kode hex-nya.
- [ ] **4.3 Gambar**: Mengumpulkan atau mendesain aset gambar, logo, atau ilustrasi yang akan dipakai di dalam website.

## FASE 5: CODE AND DEVELOPMENT (KODE DAN PENGEMBANGAN)
Fase ini adalah dokumentasi dari proses implementasi program/coding.
- [ ] **5.1 Tech Stack**: Menyebutkan dan menjelaskan teknologi yang dipakai.
  - [ ] Frontend (misal: HTML, CSS, JavaScript, Bootstrap/Tailwind)
  - [ ] Backend (misal: PHP murni atau framework seperti Laravel/CodeIgniter)
  - [ ] Database (misal: MySQL)
  - [ ] Tools Pengembangan (misal: VS Code, XAMPP, Git, Postman)
- [ ] **5.2 Tampilan Coding**: Melampirkan *screenshot* atau *snippet* kode-kode krusial dari program yang telah dibuat beserta sedikit penjelasannya.

## FASE 6: TESTING AND QUALITY ASSURANCE (PENGUJIAN DAN JAMINAN KUALITAS)
Fase ini untuk membuktikan bahwa sistem berjalan dengan baik sebelum dirilis.
- [ ] **6.1 Pengujian Sistem (Blackbox Testing)**: Membuat tabel skenario pengujian fungsionalitas (misal: Jika input form kosong lalu klik simpan, ekspektasinya muncul peringatan. Hasil aslinya apa, dan statusnya Pass/Fail).
- [ ] **6.2 Hasil Pengujian Usability Testing**: Mendokumentasikan hasil pengujian kemudahan penggunaan oleh user (bisa berupa kuesioner singkat atau umpan balik dari pengguna percobaan).

## FASE 7: DEPLOYMENT AND MAINTENANCE (PENERAPAN DAN PEMELIHARAAN)
Fase ini menjelaskan tahap perilisan website agar bisa diakses secara online.
- [ ] **7.1 Deployment**: Menjelaskan langkah-langkah atau proses meng-hosting website ke server (misal: cPanel, Vercel, Niagahoster, dll).
- [ ] **7.2 Maintenance**: Menyusun rencana pemeliharaan sistem ke depannya (seperti backup data rutin, pembaruan keamanan, atau pengecekan bug).
